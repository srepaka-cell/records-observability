# Records Observability Dashboard

Shows how many records were declared manually, by API, by a workflow, or by an object lifecycle transition in a time period, and which declaration attempts failed.

The published prototype is at https://srepaka-cell.github.io/records-observability/. The Declared count opens https://srepaka-cell.github.io/records-manager-app/ with the same declaration dates.

```bash
npm install
npm run dev
```
